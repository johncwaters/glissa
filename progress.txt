## LEARNING (important)
- DO NOT write integration tests that call start() with a real spawnCommand pointing at a live
  binary: spawning a real `node` REPL or (worse) `cmd.exe /c claude` launches an actual Claude
  session and the live PTY keeps node --test's event loop open -> the runner HANGS with no summary
  line. Use the injected `ptySpawn` fake instead. This was caught mid-run (suite stalled after the
  spawn-command file) and fixed by adding the ptySpawn seam.
- On this host `where claude` -> C:\Users\johnw\.local\bin\claude.exe (native installer, real .exe),
  so the direct path is live here; the cmd.exe path is shim-only fallback.
- This complements (does not replace) the OSC-title fix: ConPTY/claude can still set an initial
  title, which osc-title-source already ignores for ASCII-leading titles.
