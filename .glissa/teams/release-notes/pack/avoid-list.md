# Avoid list (release notes)

The Editor fails any release-notes document that uses a banned term. Words and phrases Glissa never uses,
one per line:

- revolutionary
- game-changer
- game changer
- blazing-fast
- blazing fast
- seamless
- seamlessly
- effortless
- effortlessly
- magical
- magically
- simply
- just (as a minimizer, for example "just install it")
- cutting-edge
- world-class
- supercharge
- supercharged
- unleash
- robust
- leverage (as a verb, for example "leverage the dashboard")
- cross-platform (Glissa is Windows-only; never imply it runs elsewhere)
- multi-platform
- works everywhere

Urgency phrases ("don't miss out", "act now", "limited time"), emoji, and em or en dashes are always
disallowed and do not need to be listed here.
